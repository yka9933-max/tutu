# tutu

一个本地 SillyTavern 扩展，对 AI 回复的正文做三件事：**翻译**、**润色**、**纠正**。

三个功能是平级的，各自有自己的提示词库与设置，互不从属。面板底部一行三个按钮就能直接切换。

## 安装

酒馆 → 扩展 → 安装扩展 → 填这个地址：

    https://github.com/yka9933-max/tutu

或者手动：把整个文件夹放进 public/scripts/extensions/third-party/tutu/，刷新。

装好后屏幕右下角出现一颗圆形悬浮球（🐑），点它开合面板，按住可以拖到别处，位置会记住。

## 三个功能

- **翻译**：把正文翻译成目标语言。术语表、保护标签、前置／后置提示词都可用。
- **润色**：按你的要求改写文风。内置一份武侠润色示例可作为起点。
- **纠正**：正文里出现与设定、前文对不上的地方（人物写歪了、时间线乱了、凭空编出设定）时，把它改对、把这一段理顺。

### 纠正的设定依据

纠正会读三样东西当依据：**当前聊天生效的世界书条目**（走酒馆自己的蓝绿灯机制，只取这一轮真正会命中的那些，不整本塞）、**当前角色卡**的描述／性格／场景／对话示例等字段、**最近几楼正文**。

读完的正文里明确标注了这是数据、不是指令，避免正文里的句子被当成命令执行。读不到世界书或角色卡时不会报错，降级成只看当前这一楼正文。日志里能看到本次依据的字数。不想要这一步可以在面板里关掉「读取设定依据」。

### 正文 → 纠正 → 润色

纠正只管把事情说对，不讲究文笔；文风交给紧接着的那一步润色。所以纠正完之后面板上会出现「接着润色这一楼」，点一下就用你自己的润色提示词接着处理同一楼。

## 主题

两套配色，设置里可选，也可以直接点面板右上角那颗按钮切换：

- **深色**：原来的配色，没有改动。
- **清爽浅色**：浅蓝白基底。面板、文字、边框、按钮、输入框、提示条、悬浮球都有对应颜色，不是只换背景。

选择存在浏览器本地，换聊天不会变。

## 说明

- auto_update 已关闭，不会被自动更新覆盖。
- 配置存在酒馆的扩展设置里（`extensionSettings['tutu_polish_v1']`）；API 密钥存在浏览器 localStorage（键名 `tutu_polish_key_v1`），不写进扩展设置。主题与悬浮球位置同样只存浏览器本地。
- 处理前的原文会备份，「查看原文」可以随时来回切换；同一次处理里「纠正 → 润色」接的是上一版结果。
- 「酒馆正则替换」这一条在扩展里做不到（扩展拿不到正则执行入口），已降级为按原文处理，其余功能一致。
